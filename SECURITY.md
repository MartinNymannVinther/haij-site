# Security

haij.dk is a static site: no server-side code, no database, no accounts, no
cookies. The attack surface is the nginx configuration, the build pipeline
and the dependencies, and we still want to hear about anything you find.

## Reporting

Write to martin@vintherconsulting.dk with "Security" in the subject. Please
do not open a public issue for something that could put anyone at risk.
You will get a reply within five working days, usually sooner.

## Scope

This repository only. The tools have their own SECURITY.md:

- Forretning: https://github.com/MartinNymannVinther/haij/blob/main/SECURITY.md
- Ajour: https://github.com/MartinNymannVinther/ajour/blob/main/SECURITY.md
